# Claude Workshop Course Materials

Participant and instructor materials for phData's Claude workshop courses. Each series has its own folder, and each course in a series has its own subfolder. A course folder holds its README, agenda, starter files and diagrams.

| Series | Folder | Courses |
|---|---|---|
| AI-Native SDLC | [`ai-native-sdlc/`](ai-native-sdlc/) | 6 x 90 minutes, engineers, Claude Code |

## Conventions

- One folder per course, named `NN-stage`, holding `README.md`, `agenda.md`, `starter/` and `diagrams/`.
- Instructor-only material sits in the series' `instructor/` folder.
- Scenarios are fictional and the data is synthetic. Do not commit client data.
- Course templates for the workshop app are imported as CSV/JSON and live outside this repo.
